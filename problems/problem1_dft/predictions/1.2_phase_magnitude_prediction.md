# Pre-implementation prediction — §1.2 Phase vs. Magnitude Isolation

**Date: 2026-10-18** (written and committed before running any code for §1.2)

## Setup

Let `f(x,y)` be the test image with DFT `F(u,v) = |F(u,v)| e^{jφ(u,v)}`. Let `n(x,y)` be
a realization of uniform white noise with DFT `N(u,v) = |N(u,v)| e^{jψ(u,v)}`. The
experiment reconstructs

```
G(u,v) = |N(u,v)| · e^{jφ(u,v)}
```

i.e. the *phase of the test image* combined with the *magnitude of the noise*, then
takes `g(x,y) = IDFT{G}`.

## Derivation

Write `P(u,v) = e^{jφ(u,v)}`, the unit-magnitude "phase-only" spectrum of the test
image, and `p(x,y) = IDFT{P}` — this is exactly the reconstruction used in part (a)
with a perfectly flat magnitude of 1. Since `G(u,v) = |N(u,v)| · P(u,v)` is a product of
two spectra, the 2-D Convolution Theorem gives, in the spatial domain,

```
g(x,y) = m(x,y) ⊛ p(x,y),       m(x,y) = IDFT{|N(u,v)|}
```

(circular convolution, since this is a discrete, periodic DFT).

For white noise, `|N(u,v)|` is, in expectation over realizations, **flat** across
`(u,v)` — white noise has a flat power spectrum. For one realization it is not exactly
flat: it fluctuates around a constant mean `c = E[|N(u,v)|]` with zero-mean, broadband
fluctuations `δ(u,v) = |N(u,v)| − c`. Splitting `m(x,y) = c·δ_0(x,y) + IDFT{δ}` (where
`δ_0` is the discrete impulse, since `IDFT{c} = c·δ_0`), and because `δ(u,v)` is
broadband/incoherent, `IDFT{δ}` is itself a low-amplitude, noise-like function spread
over the whole `(x,y)` plane rather than concentrated at one point.

Substituting back:

```
g(x,y) ≈ c · p(x,y)  +  (IDFT{δ} ⊛ p)(x,y)
```

**Prediction:** the reconstruction should look essentially like the flat-magnitude,
phase-only reconstruction from part (a) — i.e. the edges, object boundaries and overall
structure of the original test image should be clearly recognizable, because phase
carries the localization/structural information and dominates the first term. On top of
that, I expect a visible **fine-grained speckle/graininess** superimposed on the image,
coming from the second term, because the noise magnitude is only flat *on average*, not
exactly flat for a single realization — unlike part (a), which uses a magnitude that is
*exactly* constant by construction and should therefore look cleaner/less grainy.

## What I'll check against this prediction

- Whether the dominant visible structure in the part-(b)... (here, the noise-magnitude
  reconstruction) matches the flat-magnitude image from part (a) up to added speckle.
- Whether the speckle amplitude scales with how far `|N(u,v)|` deviates from its mean
  (e.g. I'd expect a wider noise distribution / higher noise variance to produce more
  visible speckle, since `δ(u,v)` has larger spread).
- If the result looks nothing like part (a) (e.g. structure not recognizable at all),
  that would be a discrepancy to reconcile — the likely cause would be |N(u,v)| not
  being as flat as assumed for the specific noise realization/parameters used (e.g. if
  the noise variance is tiny, its DFT magnitude could be small relative to numerical
  floor across most frequencies, distorting the relative weighting versus the DC term).
